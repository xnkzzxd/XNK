# PRD — Fase Y: portal klien terasa seperti aplikasi Mac di tablet, laptop, PC

## Masalah
T-1913 hanya melebarkan tampilan HP (band hitam, kartu besar, dua kolom). Pemilik: "tampilan di desktop, tablet, PC harus berbeda dari mobile; yang sekarang tidak terasa seperti aplikasi Windows/Mac".

## Keputusan pemilik (2026-11-15)
| Hal | Keputusan |
| --- | --- |
| Gaya | Mac (Apple Fitness/Health); hitam-putih + warna aksen tetap |
| Bilah judul | Terang ala Mac: bilah tipis (judul + tombol aksi kanan), sidebar abu muda; kartu hitam hanya untuk yang penting |
| Detail & isian | Campuran: detail (sesi, rutinitas, makanan, momen, info) di panel kanan; isian singkat (booking, ubah profil, ukur, konfirmasi) di jendela tengah; pencatat latihan tetap layar penuh |
| Panel kanan | Muncul saat sesuatu dipilih; tanpa pilihan isi memakai lebar penuh |
| Tablet | Seperti desktop (tegak & rebah), target sentuh tetap 44 px pada layar sentuh |
| Perilaku | Hover dan klik kanan; tampilan rapat. Pintasan keyboard tidak diminta |
| Cakupan | Portal klien saja; panel coach tidak berubah |
| Kalender | Kontras tinggi (komentar mockup): hari bisa-dipilih berupa kotak abu berisi, lewat pudar, penuh dicoret, kepala hari dan garis kisi jelas |
| Ruang kosong | Tidak boleh ada ruang kosong besar (komentar mockup); halaman mengisi lebar dan tinggi layar |

## Di luar cakupan
HP (< 768 px) tidak berubah sama sekali. Tidak ada fitur atau data server baru.
