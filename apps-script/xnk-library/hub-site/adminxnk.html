XNK Pusat perlu disiapkan

Izin Google hanya bisa diberikan dari editor Apps Script (sekali saja):

  1. Tekan Buka editor XNK Pusat (login dengan akun pemilik XNK Pusat).
  2. Di atas, pilih fungsi setupPusat lalu tekan Run.
  3. Pilih akun → Advanced → Go to XNK Pusat → Allow.
  4. Kembali ke sini dan tekan Cek semua sekarang.
