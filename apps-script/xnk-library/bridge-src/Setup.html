Setup XNK

Empat langkah. Bisa dibuka ulang kapan saja dari menu XNK → Mulai setup.

1. Siapkan spreadsheet

Membuat sheet yang dibutuhkan, kunci keamanan, dan pengingat otomatis. Google akan meminta izin sekali: pilih akun Anda, lalu Izinkan.

Kalau ini salinan dari spreadsheet lain, semua pengaturan lama (PIN, Telegram, dll.) dihapus supaya tidak terbawa.

2. Nama usaha dan PIN

Ringkasan pengingat (dengan tombol WhatsApp per klien) dikirim ke email ini bila Telegram belum diatur.

3. Terbitkan aplikasi

Langkah ini harus diklik sendiri (aturan Google):

  1. Menu Ekstensi → Apps Script.
  2. Di kanan atas, klik Terapkan (Deploy) → Deployment baru.
  3. Ikon roda gigi → pilih Aplikasi web.
  4. Jalankan sebagai: Saya. Yang memiliki akses: Siapa saja.
  5. Klik Terapkan, beri izin bila diminta.

Sudah? Klik tombol di bawah.

4. Alamat untuk klien

Pilih nama untuk alamat Anda: huruf kecil, angka, dan tanda hubung (3 sampai 30 karakter).

xnk.web.id/

    Daftarkan ke XNK Pusat

    Supaya pengelola XNK bisa memantau kesehatan aplikasi ini (versi, pengingat, jumlah klien — tanpa nama atau nomor klien). Minta kodenya ke pengelola XNK.

    Pakai link dari Deploy → Kelola deployment (akses “Siapa saja”), bukan link uji.

    Kirim ke pengelola XNK

    Supaya alamat Anda aktif, kirim data ini ke pengelola XNK (mis. lewat WhatsApp).

    Sesudah diaktifkan, bagikan link portal klien Anda ke klien.
