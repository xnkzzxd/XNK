# Folder custom

Berkas di folder ini disalin ke situs **paling akhir**, jadi menimpa berkas bawaan yang namanya sama.
Pembaruan dari XNK tidak pernah mengubah folder ini.

Contoh:
- `icon.svg`: ganti ikon situs (bawaan: huruf pertama nama usaha).
- `halaman/tentang.html`: halaman tambahan, terbuka di `https://<situs Anda>/halaman/tentang.html`.

Jangan menaruh PIN, token, atau rahasia lain di sini; repo ini bisa dilihat orang lain kalau publik.
